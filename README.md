## Como instalar a extensão no navegador

1. Clone este repositório:

2. Acesse no Chrome: chrome://extensions

3. Ative o **Modo do desenvolvedor** (canto superior direito)

4. Clique em **"Carregar sem compactação"**

5. Selecione a pasta do projeto (`controle-parental/`)

A extensão será carregada e já estará disponível na barra do navegador.

> Observação: esta extensão foi desenvolvida para fins acadêmicos e de pesquisa,
> utilizando a Chrome Extension API (Manifest V3).
